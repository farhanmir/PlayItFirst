## Two-minute live demo

- 0:00–0:15: hook and aspiring entrepreneur problem.
- 0:15–0:35: verified matched listing, scan and animated reconstruction; real rent affects opening funds. If public uses mock, show authorized local real-property demo honestly.
- 0:35–1:00: judge joins via QR, manually takes, brews and serves. Actual sale and stock consumption.
- 1:00–1:20: second player edits pickup/counter; both see change and actual customer route responds. Measured outcomes only.
- 1:20–1:45: Jamie inspects rush/stock/cash and proposes $35 restock. Owner approves; actual receipt and state. If verified, show real Photon message/call and Nessie receipt as part of same action. Use short prerecorded evidence if provider latency would break demo.
- 1:45–2:00: launch blueprint and closing.
