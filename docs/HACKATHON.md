### Timing and honest fallbacks

- Rehearse the full route in the selected building. If one order takes longer than 31 seconds, start the service segment earlier and shorten narration; do not skip brewing, inject a sale or substitute fabricated footage.
- Jamie begins assistance only after the human's first sale and the normal idle grace. If Jamie has not started by the allotted segment, show the current standby/task label or a short **labeled recorded local demonstration**. Do not claim personal work from team totals.
- A prior manual edit can remove the available pickup improvement. Rehearse a layout that still yields a valid suggestion. If no improvement exists, report that result and use a verified restock proposal as the approved-action example. Do not force a move or fabricate savings.
- If provider latency breaks the timing, use a short labeled recording of an actual successful provider run with its build and date, or explicitly demonstrate local rules. Do not attribute a local fallback to Gemini/Deepagents execution.
- If the public property, walkthrough or newest feature fails its preflight, use an authorized local demo and say so. A safe mock fallback must be labeled mock.
- Keep Photon and Nessie outside this core two-minute script until their actual external receipts are verified. WebRTC crew voice is not a telephone call. Local finance is not Nessie settlement.
