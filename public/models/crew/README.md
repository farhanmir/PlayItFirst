# Café crew assets

Kenney, Animated Characters 3 (1.1), CC0 1.0 Universal.
Source: https://opengameart.org/content/animated-characters-3
Official creator: https://kenney.nl/
Downloaded 2026-11-14 from https://opengameart.org/sites/default/files/kenney_animated-characters-3.zip

The human male and female skins, characterMedium mesh, idle and run animations
were converted from the original FBX/PNG files to binary glTF with Blender.
Animation bone matrices were baked onto the model rest rig before export to resolve
the source FBX rest-pose differences. Runtime material shading varies the shirt
color deterministically without recoloring faces or shoes.
Only human skins are included. No restricted sponsor property assets are included.
